# Support

Use GitHub issues for reproducible software defects, scoped feature proposals, and
documentation problems. Use GitHub Discussions at the organization level, when
available, for open-ended design questions.

This project cannot provide medical advice, interpret health records, or respond to
clinical emergencies. Contact a qualified healthcare professional or local emergency
service for those needs. Send security-sensitive reports through [SECURITY.md](SECURITY.md),
not a public support channel.
